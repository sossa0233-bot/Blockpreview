# Blockpreview
Blog Preview Card

A simple HTML & CSS project showcasing a blog preview card with an image, title, description, and author section. The design is responsive-friendly and uses modern fonts.

Features

Card Layout: Clean blog card with an image, tag, date, title, and description.

Author Section: Circular profile image with author name for a personal touch.

Custom Fonts: Uses Figtree
 and Roboto
 from Google Fonts.

Responsive Design: The card layout adjusts to different screen sizes.
